# Submissions

Every project submitted to Projek Seratus is one file in this folder, named after its title (`peta-banjir.md`).

To submit, use the form at https://projek-seratus.artifisi.com/apply. It fills in the file for you and opens a pull request. You can also add the file by hand:

```markdown
---
title: "Peta Banjir"
github_url: https://github.com/aisyahr/peta-banjir
website_url: https://peta-banjir.example.com   # optional
---
```

You don't pick a slot. Projects are ranked by their GitHub stars, refreshed every day, and the 100 most-starred fill the board.
