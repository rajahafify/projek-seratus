# Projek Seratus

**Seratus projek. Satu tujuan.** · One hundred projects. One cause.

Projek Seratus is a community effort to build 100 projects for a common cause. Every project fills one slot on a 10×10 board until all hundred are done.

This repository is the open-source kit, so anyone can start their own Projek Seratus for their school, office, kampung or city.

## What's here

- `index.html` — the landing page and the 100-slot board, in English and Bahasa Melayu (toggle at the top right). One self-contained file, no build step.

## Start your own

1. Fork this repository.
2. Edit `index.html` to set your cause, your name and your colours. Bahasa Melayu text lives in the `MS` object in the script at the bottom; English text is in the HTML.
3. In your fork, go to **Settings → Pages** and publish from the `main` branch.

Your board goes live at `https://<your-name>.github.io/projek-seratus`.
