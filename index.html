Why a hundred

Big enough to matter. Small enough to finish.

One project rarely moves a cause. A hundred of them, built by different people with different skills, start to add up to something people notice.

A fixed number keeps everyone honest. The board shows exactly how far the community has come and how many slots are still open, so anyone can see where to help next.

How it works

From idea to slot filled

  1. Step 1

    Pick the cause

    Each Projek Seratus is built around one cause the whole community agrees on, written down so every project can point back to it.

  2. Step 2

    Claim a slot

    Pitch your project in a few lines and take the next open number. Work alone or gather a small team.

  3. Step 3

    Build in the open

    Share progress as you go. Ask for help, lend a hand on someone else's slot, and keep the work visible.

  4. Step 4

    Ship it

    Show what you made and how it serves the cause. Your slot turns gold on the board, and the count moves one closer to 100.

Open source

Start your own Projek Seratus

Projek Seratus is open source. Fork it, set your own cause, and run a hundred projects with your school, your office, your kampung or your city.

  • This page and its 100-slot board come ready to use.
  • It's a single HTML file, so changing the cause, the name and the colours is a quick edit.
  • Host it for free on any static host, such as GitHub Pages.
  • Keep it open. Share what you improve so the next Projek Seratus starts further ahead.

# 1. Fork on GitHub, then clone your copy
git clone https://github.com/your-name/projek-seratus.git
cd projek-seratus

# 2. Set your cause and name in index.html

# 3. Push, then turn on GitHub Pages
git commit -am "Start our Projek Seratus"
git push origin main

In your fork, open Settings → Pages and publish from the main branch. Your board goes live at your-name.github.io/projek-seratus.

Questions

Good to know

Does it cost anything?
No. Joining is free, and the Projek Seratus code is free to use, change and share.
What counts as a project?
Anything that serves the cause and can be shown when it's done. One person can finish a small one in a weekend.
Can I take more than one slot?
Yes, once your first project ships. That keeps slots open for newcomers.
What happens at 100?
The community celebrates, shares what all hundred projects achieved, and decides whether to start the next hundred.
